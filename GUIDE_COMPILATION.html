🫀 CardioLearn ECG — Guide de compilation APK

Guide complet pour compiler l'application Android à partir du code source

📋 Prérequis — À installer avant de commencer

🟢

Node.js LTS

Version 18 ou 20. Télécharger sur nodejs.org

☕

Java JDK 17

JDK 17 (LTS). Télécharger sur adoptium.net

🤖

Android Studio

Version Hedgehog ou plus récente. Sur developer.android.com

🧰

Android SDK

SDK 34 (Android 14). Installé automatiquement avec Android Studio.

⚠️ Important : Installer Node.js et le JDK avant Android Studio. Configurez les variables d'environnement JAVA_HOME et ANDROID_HOME si demandé.

📁 Structure des fichiers fournis

ecg-app/
  ├── package.json ← dépendances du projet
  ├── capacitor.config.ts ← config Capacitor (app ID, nom...)
  ├── vite.config.ts ← config du build React
  ├── index.html ← point d'entrée HTML
  └── src/
    ├── main.jsx ← initialisation React
    └── App.jsx ← application ECG complète

Le dossier android/ sera généré automatiquement par Capacitor à l'étape 4.

🚀 Étapes de compilation

1
Placer les fichiers et ouvrir un terminal
⏱ ~2 min

Copier le dossier ecg-app/ où vous voulez (ex: Bureau, Documents). Puis ouvrir un terminal dans ce dossier :

💡 Windows : clic droit dans le dossier → "Ouvrir dans le terminal"
💡 Mac/Linux : ouvrir Terminal et taper cd ~/Bureau/ecg-app
cd ecg-app
2
Installer les dépendances npm
⏱ ~2-5 min (selon la connexion)
npm install
💡 Cette commande télécharge React, Capacitor, Vite et tous les outils nécessaires dans le dossier node_modules/. Un fichier package-lock.json est créé automatiquement.
3
Builder l'application React (production)
⏱ ~30-60 secondes
npm run build

Cette commande compile le code JSX en JavaScript optimisé et crée le dossier dist/. C'est ce dossier que Capacitor va intégrer dans l'APK.

✅ Vous devriez voir : dist/index.html, dist/assets/
4
Initialiser et ajouter la plateforme Android
⏱ ~2-4 min
⚠️ À faire une seule fois. Si le dossier android/ existe déjà, passer à l'étape 5.
npx cap init "CardioLearn ECG" "com.cardiolearn.ecg" --web-dir dist
puis
npx cap add android
💡 Capacitor crée le dossier android/ — c'est un projet Android Studio complet. Ne pas le modifier manuellement sauf si vous savez ce que vous faites.
5
Synchroniser le build dans le projet Android
⏱ ~15 secondes

À chaque modification du code, exécuter :

npx cap sync android

Cette commande copie le contenu de dist/ dans le projet Android et met à jour les plugins Capacitor.

6
Ouvrir Android Studio et compiler l'APK
⏱ ~5-15 min
npx cap open android

Dans Android Studio :

  1. Attendre la fin de la synchronisation Gradle (barre de progression en bas)
  2. Menu Build → Build Bundle(s) / APK(s) → Build APK(s)
  3. Attendre la compilation (~5-10 min la première fois)
  4. Cliquer sur "locate" dans la notification en bas à droite
✅ L'APK se trouve dans : android/app/build/outputs/apk/debug/app-debug.apk
💡 Pour un APK release (signé, pour le Play Store), aller dans Build → Generate Signed Bundle / APK et créer un keystore.
7
Installer l'APK sur votre Android
⏱ ~2 min

Trois méthodes :

📱 Méthode 1 — Via Android Studio (plus facile)
Brancher le téléphone en USB → activer le débogage USB dans les options développeur → cliquer sur le bouton ▶ "Run" dans Android Studio.
📂 Méthode 2 — Copier l'APK manuellement
Copier app-debug.apk sur le téléphone (câble USB, WhatsApp, email…) → ouvrir le fichier sur Android → "Installer" (autoriser les sources inconnues si demandé).
⚡ Méthode 3 — ADB (ligne de commande)
adb install android/app/build/outputs/apk/debug/app-debug.apk

🔄 Workflow de mise à jour

↑
Après chaque modification du code source
npm run build # recompile le React
npx cap sync android # synchronise dans Android Studio

Puis dans Android Studio : Build → Build APK(s) à nouveau.

🐛 Problèmes fréquents

!
Erreur "JAVA_HOME not found"

Java n'est pas dans le PATH système. Solution :

# Windows (PowerShell, adapter le chemin)
[System.Environment]::SetEnvironmentVariable("JAVA_HOME","C:\Program Files\Eclipse Adoptium\jdk-17.0.X.X-hotspot","Machine")

# Mac/Linux (ajouter dans ~/.bashrc ou ~/.zshrc)
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk
!
Erreur "SDK location not found"
# Créer le fichier android/local.properties et y ajouter :
# Windows :
sdk.dir=C\:\\Users\\VOTRE_NOM\\AppData\\Local\\Android\\Sdk
# Mac :
sdk.dir=/Users/VOTRE_NOM/Library/Android/sdk
!
Erreur Gradle lors du premier build

Dans Android Studio : File → Sync Project with Gradle Files. Si ça persiste : Build → Clean Project puis relancer le build.

!
L'assistant IA ne répond pas dans l'appli

L'API Anthropic nécessite une connexion internet. Vérifier que le téléphone a du réseau. Si l'erreur persiste en WiFi, le firewall ou le réseau bloque peut-être les requêtes vers api.anthropic.com.
